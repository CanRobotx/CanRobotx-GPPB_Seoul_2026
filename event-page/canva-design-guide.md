**피드 이미지 (추천)**
- 크기: 1200 × 630px
- 비율: 1.91:1
- 용량: 최대 8MB
- 형식: JPG, PNG

**링크 공유 이미지**
- 크기: 1200 × 630px
- 비율: 1.91:1
- 텍스트는 이미지의 20% 이하 권장

**커버 사진**
- 데스크톱: 820 × 312px
- 모바일: 640 × 360px

**피드 정사각형 (추천)**
- 크기: 1080 × 1080px
- 비율: 1:1
- 용량: 최대 30MB
- 형식: JPG, PNG

**피드 세로**
- 크기: 1080 × 1350px
- 비율: 4:5

**스토리**
- 크기: 1080 × 1920px
- 비율: 9:16
- 텍스트/로고는 상하단 250px 안전 영역 외부에 배치

**릴스 (Reels)**
- 크기: 1080 × 1920px
- 비율: 9:16
- 영상 길이: 15초~90초

**헤더 이미지**

## 🎯 Canva 템플릿 제작 가이드

### 1. Canva Brand Kit 설정

**Step 1: Brand Kit 만들기**
1. Canva 좌측 메뉴 → "Brand Kit" 클릭
2. "Create a new brand kit" 선택
3. 브랜드명: "GPPB Seoul 2026"

**Step 2: 색상 팔레트 추가**
1. "Brand colors" 섹션
2. 위 "브랜드 컬러 팔레트"의 모든 색상 추가
3. 각 색상에 이름 지정 (예: "Primary Blue", "A-Track Green")

**Step 3: 폰트 설정**
1. "Brand fonts" 섹션
2. Heading: Pretendard Bold (또는 Noto Sans KR Bold)
3. Subheading: Pretendard SemiBold
4. Body: Pretendard Regular

### 2. 재사용 가능한 요소 만들기

**A. 그라데이션 배경**
1. 사각형 도형 삽입 (캔버스 전체 크기)
2. Fill → Gradient 선택
3. 각도 135도 설정
4. 색상 포인트:
   - 0%: #0078D4
   - 50%: #00BCF2
   - 100%: #FF6B35
5. "Save as template" 또는 복사하여 재사용

**B. 트랙 헤더 템플릿**
```
A트랙: 녹색 그라데이션 (#28A745 → #34CE57)
B트랙: 파란색 그라데이션 (#0078D4 → #00BCF2)
C트랙: 주황색 그라데이션 (#FF6B35 → #FF8C42)
```

**C. 정보 카드 스타일**
- 배경: 흰색 (#FFFFFF)
- 테두리: 1px solid #ddd (선택적)
- Border Radius: 12-16px
- 그림자: 0 4px 16px rgba(0,0,0,0.1)
- 패딩: 24-32px

### 3. 텍스트 스타일 프리셋

Canva에서 자주 사용하는 텍스트 스타일 저장:

**"H1 Main Title"**
- 폰트: Pretendard Bold
- 크기: 56px
- 색상: #FFFFFF (또는 #333333)
- Letter spacing: -1.2px
- Line height: 1.2

**"H2 Section Title"**
- 폰트: Pretendard Bold
- 크기: 40px
- 색상: #333333
- Letter spacing: -0.8px

**"Body Regular"**
- 폰트: Pretendard Regular
- 크기: 20px
- 색상: #666666
- Letter spacing: -0.3px
- Line height: 1.6

**"Caption Small"**
- 폰트: Pretendard Regular
- 크기: 16px
- 색상: #999999
- Letter spacing: -0.2px

### 4. 공통 요소 라이브러리

**버튼 스타일**
```css
Primary Button:
  배경: #0078D4
  텍스트: #FFFFFF, 18-20px, Bold
  패딩: 15-20px (상하), 40-50px (좌우)
  Border Radius: 8px
  그림자: 0 4px 12px rgba(0,120,212,0.3)

Secondary Button:
  배경: #FFFFFF
  텍스트: #0078D4, 18-20px, Bold
  테두리: 2px solid #0078D4
  패딩: 15-20px (상하), 40-50px (좌우)
  Border Radius: 8px
```

**태그/라벨 스타일**
```css
Info Tag:
  배경: rgba(255,255,255,0.2) (흰 배경 위) 또는 #f8f9fa (색상 배경 위)
  텍스트: 14-16px, Medium
  패딩: 6-8px (상하), 12-16px (좌우)
  Border Radius: 20px
```

## 📱 채널별 최적화 팁

### 인스타그램
- **피드**: 정사각형 (1:1) 또는 세로 (4:5) 사용
- **첫 3초**: 눈길을 끄는 비주얼과 텍스트 배치
- **텍스트 양**: 이미지당 최대 30단어 이내
- **CTA**: 마지막 슬라이드에 명확한 행동 유도
- **해시태그**: 캡션에 20-30개 포함

### 페이스북
- **비율**: 1.91:1 (가로형) 권장
- **텍스트**: 이미지 내 텍스트 20% 이하
- **가독성**: 모바일 피드에서도 읽기 쉽게
- **링크 프리뷰**: 메타 태그 최적화

### 트위터 / X
- **비율**: 16:9 (가로형) 또는 2:1
- **파일 크기**: 5MB 이하
- **텍스트**: 간결하고 임팩트 있게
- **대체 텍스트**: 이미지 설명 추가 (접근성)

### 링크드인
- **전문성**: 비즈니스 톤 유지
- **데이터**: 인포그래픽 효과적
- **문서 공유**: PDF 형태로도 공유 가능

## 🔧 Canva 작업 워크플로우

### 1단계: 준비
1. Brand Kit 설정 완료
2. 발표자 이미지 Canva에 업로드
3. 로고/아이콘 소재 준비 (필요시)

### 2단계: 마스터 템플릿 제작
1. 첫 번째 슬라이드를 마스터로 제작
2. 여백, 폰트, 색상 시스템 적용
3. "Duplicate" 하여 나머지 슬라이드 생성

### 3단계: 콘텐츠 채우기
1. 텍스트 내용 복사-붙여넣기
2. 이미지 교체
3. 색상 및 레이아웃 조정

### 4단계: 일관성 체크
- 모든 슬라이드 여백 동일한지 확인
- 폰트 크기 일관성 확인
- 색상 팔레트 내에서만 사용했는지 확인
- 오타 및 문법 검사

### 5단계: 내보내기
1. "Download" 버튼 클릭
2. 파일 형식 선택:
   - JPG: 일반 사용 (파일 크기 작음)
   - PNG: 고품질 필요 시
3. 품질: "Best quality" 선택
4. "All pages" 선택하여 한 번에 다운로드

### 6단계: 최종 검수
- 파일명 규칙: `GPPB2026_Instagram_01.jpg` ~ `GPPB2026_Instagram_10.jpg`
- 이미지 크기 확인: 1080 × 1080px
- 색상 프로필: sRGB
- 파일 크기: 각 1MB 이하 권장
