## 🎨 Canva 제작 팁

### 1. 템플릿 선택
- Canva에서 "Instagram Post (Square)" 선택
- 빈 캔버스에서 시작하거나, 유사한 템플릿 활용 후 수정

### 2. 색상 팔레트 설정
Canva 좌측 "Brand Kit"에 다음 색상 저장:
- Primary Blue: #0078D4
- Light Blue: #00BCF2
- Orange: #FF6B35
- Green: #28A745
- Light Green: #34CE57
- Orange Red: #FF8C42
- Gray 1: #333333
- Gray 2: #666666
- Gray 3: #999999
- Background Gray: #f8f9fa

### 3. 폰트 설정
- 한글: Pretendard (없으면 Noto Sans KR)
- 영문/숫자: Inter (없으면 Pretendard)
- 이모지: 시스템 기본 (Apple Color Emoji, Segoe UI Emoji)

### 4. 그라데이션 만들기
1. 도형(사각형) 삽입
2. "Fill" → "Gradient" 선택
3. 각도 135도 (좌상→우하)
4. 색상 포인트 추가 (시작, 중간, 끝)

### 5. 일관성 유지
- 모든 슬라이드를 한 번에 작업
- 스타일 가이드 준수 (여백, 폰트 크기, 색상)
- 마스터 레이아웃 활용

### 6. 내보내기
- 파일 형식: JPG (파일 크기 작음) 또는 PNG (고화질)
- 품질: 최고 품질 선택
- 크기: 1080 × 1080px 유지

### 7. 순서대로 업로드
- 인스타그램 피드에 1번부터 10번까지 순서대로 업로드
- 캡션과 해시태그는 첫 번째 이미지에만 추가
- 위치 태그: "Microsoft Korea" 또는 "종로구, 서울"
